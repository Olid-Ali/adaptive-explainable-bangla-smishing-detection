# Designing and Evaluating an Adaptive, Explainable Interface for Bangla Smishing Detection

This repository contains the implementation of the research project **“Designing and Evaluating an Adaptive, Explainable Interface for Bangla Smishing Detection.”**

The project develops a system that detects Bangla SMS messages as **NORMAL, PROMO, or SPAM/SMISHING**, identifies important evidence behind the prediction using **Explainable AI (XAI)**, and generates explanations that can be adapted to different user expertise levels.

---

## Project Workflow

The project is divided into three main stages:

```text
EDA & Preprocessing
        ↓
Bangla_Smishing_P1
(Model Training + XAI + Explanation Dataset)
        ↓
Bangla_Smishing_P2
(BanglaT5 Fine-tuning + Adaptive Explanation)
```

Each stage uses the output of the previous stage.

---

## 1. EDA & Preprocessing

This stage contains the exploratory data analysis and verification of the combined SMS dataset.

### Main tasks

- Explore the combined datasets
- Analyze dataset size and structure
- Analyze class distribution
- Check missing values and duplicates
- Analyze SMS text characteristics
- Verify the existing train/validation/test split
- Prepare the dataset for model development

### Output

The processed dataset is used as the input for `Bangla_Smishing_P1`.

---

# 2. Bangla_Smishing_P1

`Bangla_Smishing_P1` contains the main **SMS classification, XAI, confidence calibration, and explanation-dataset generation pipeline**.

## 2.1 Model Training

The project performs model training/evaluation for Bangla SMS classification.

The main classification model is:

**BanglaBERT — `csebuetnlp/banglabert`**

The classification task contains three classes:

```text
NORMAL
PROMO
SPAM
```

Other language models are used for explanation-related tasks.

### Models and roles

| Model | Role |
|---|---|
| BanglaBERT | Primary SMS classifier and XAI target |
| SmolLM-135M | Evidence-constrained stylistic refinement |
| BanglaGPT | Explanation quality auditing |
| BanglaT5 | Final explanation generation model |

---

## 2.2 Explainable AI

After training the classifier, XAI is used to identify the words or text spans that contribute to the model's prediction.

The main XAI method is:

**Integrated Gradients (IG)**

The extracted evidence is cross-checked using:

**Leave-One-Out (LOO) analysis**

The XAI pipeline includes:

- Sub-word attribution aggregation
- Directional filtering
- Semantic typing
- Evidence selection
- Sparsity-based truncation
- Substring verification

Example:

```text
SMS:
"আপনি পুরস্কার জিতেছেন। এখনই ক্লিক করুন..."

Prediction:
SPAM

Important evidence:
"পুরস্কার"
"জিতেছেন"
"এখনই"
"ক্লিক করুন"
```

---

## 2.3 Confidence Calibration

The classifier confidence is calibrated using **temperature scaling** on the validation set.

This provides a more reliable confidence value for the predicted class.

---

## 2.4 XAI Evaluation

The extracted evidence is evaluated using perturbation-based metrics:

- **Comprehensiveness**
- **Sufficiency**
- **Leave-One-Out validation**

These evaluations measure whether the identified evidence is actually important to the model's decision.

---

## 2.5 Explanation Dataset Generation

The XAI evidence generated in P1 is used to create an explanation dataset.

The dataset contains information such as:

```text
SMS
Predicted Label
Confidence
XAI Evidence
Static Explanation
Adaptive Explanation
```

The explanation generation process produces **3,120 explanation instances**.

The candidate explanations are checked using three levels of validation:

1. **Deterministic rule-based validation**
2. **LLM-based quality auditing**
3. **Human expert validation**

### Output of P1

The main output of P1 is the **XAI-based explanation dataset**.

This dataset becomes the training data for `Bangla_Smishing_P2`.

---

# 3. Bangla_Smishing_P2

`Bangla_Smishing_P2` uses the explanation dataset generated by P1 to fine-tune **BanglaT5**.

## 3.1 Explanation Dataset

The explanation dataset from P1 is loaded and used as supervised training data.

It provides the model with information such as:

- SMS text
- Predicted class
- Confidence
- XAI evidence
- Target explanation

---

## 3.2 BanglaT5 Fine-tuning

**BanglaT5 (`csebuetnlp/banglat5`)** is fine-tuned to transform the verified XAI evidence into natural-language explanations.

The purpose is to generate explanations that are understandable while remaining consistent with the classifier's evidence and prediction.

---

## 3.3 Adaptive Explanations

The system supports different explanation levels based on user expertise.

```text
Low
↓
Simple Bangla explanation + clear safety/action message

Medium
↓
More detailed explanation of the suspicious evidence

High
↓
Detailed/technical explanation with more information
```

The goal is to avoid giving every user the same fixed explanation.

# Project Goal

The system is designed to answer two main questions:

**1. Is this SMS suspicious?**

**2. Why did the AI make this decision?**

Rather than providing only a classification result, the system provides **evidence-based explanations** and adapts the explanation according to the user's level of expertise.
